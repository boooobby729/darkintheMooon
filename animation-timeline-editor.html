动画时间轴编辑器 — 快速入门

    
这是一个可视化的动画时序编辑工具，帮助你精确调整 H5 页面中多个动画元素的播放时间、缓动曲线和属性变化，然后生成 Prompt 交给 AI 去修改代码。


    
开始使用

    
1
在下方「目标文件路径」中填写你的 HTML 文件路径（支持相对路径如 ../my-project/index.html，或 HTTP URL）。也可以直接把 HTML 文件拖到右侧预览区域。

    
2
点击左侧轨道列表选中一个动画元素，右侧会显示实时预览和动画曲线。在下方属性面板中填写 CSS 选择器（如 #myElement）来关联实际 DOM 元素。

    
3
拖动时间轴上的色条调整开始时间和时长，或在属性面板中精确输入数值。点击标尺可以定位到任意时间点预览。

    
4
调整完成后，点击右上角「复制 Prompt」，将生成的修改指令粘贴给 AI 助手执行代码修改。


    
预览 HTML 文件

    
如果使用相对路径或绝对路径，需要通过 HTTP 服务器访问本编辑器。最简单的方式：在项目的上级目录运行 python3 -m http.server 8080，然后在浏览器中打开 http://localhost:8080/path/to/animation-timeline-editor.html。

    
如果使用绝对路径（如 /Users/me/project/index.html），需要在「服务器根目录」中填写 HTTP 服务器启动时所在的目录路径。


    
数据持久化

    
所有轨道数据会自动保存到浏览器 localStorage。你也可以用「导出」按钮保存为 JSON 文件，方便分享给同事或在其他电脑上「导入」继续编辑。
